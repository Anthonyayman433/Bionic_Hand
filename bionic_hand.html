About the Project

The Bionic Hand is a 5-degree-of-freedom robotic hand replica controlled wirelessly over Wi-Fi. Each finger is driven by a dedicated SG90 micro-servo, managed through a PCA9685 16-channel PWM breakout board over I²C, connected to an ESP32 microcontroller acting as a Wi-Fi access point or client.

The ESP32 exposes a lightweight HTTP API — control commands are sent as simple GET requests, making integration with any platform (Python, JavaScript, mobile) trivial. The system supports three control modes: real-time MediaPipe hand mirroring, predefined sign language gestures, and direct keyboard hotkey control.

Key Features

  • Real-time finger angle mapping using MediaPipe Hands landmark detection (21 points)
  • Configurable motor inversion per channel for physically reversed servo mounting
  • Throttled command dispatch (20 Hz max) with delta-threshold filtering to reduce noise
  • Predefined gesture library for sign language words (hi, yes, help, water, thanks)
  • Full per-motor forward/backward keyboard control with group preset commands
  • All servo angles mapped to 0°–180° with smooth transitions via PCA9685 PWM
